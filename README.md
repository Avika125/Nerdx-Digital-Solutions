# Nerdx - Digital Solutions Agency

![Nerdx Banner](https://via.placeholder.com/1200x400?text=Nerdx+Digital+Solutions)

**Nerdx** is a modern, high-performance website for a digital solutions agency. Built with React, Tailwind CSS, and Framer Motion, it features a premium, animated UI that showcases the agency's philosophy ("NERD"), services, and workflow.

## 🚀 Built With

-   **[Vite](https://vitejs.dev/)** - Next Generation Frontend Tooling
-   **[React](https://reactjs.org/)** - A JavaScript library for building user interfaces
-   **[Tailwind CSS](https://tailwindcss.com/)** - Rapidly build modern websites without ever leaving your HTML
-   **[Framer Motion](https://www.framer.com/motion/)** - A production-ready motion library for React
-   **[React Router](https://reactrouter.com/)** - Declarative routing for React

## ✨ Features

-   **Premium UI/UX**: Glassmorphism effects, rich gradients, and a dark-themed aesthetic.
-   **Interactive Animations**: Smooth scroll animations, hover effects, and entrance transitions powered by Framer Motion.
-   **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
-   **Modular Architecture**: Clean project structure with separated pages and reusable components.
-   **Detailed Service Pages**:
    -   **Who We Are**: Agency philosophy and background.
    -   **How We Work**: The "NERD" framework (Navigate, Explode, Refine, Define) and detailed workflow stages.
    -   **What We Do**: Comprehensive service breakdown (Strategy, Design, Tech, AI).
-   **Contact Integration**: Functional contact form layout.

## 📂 Project Structure

```bash
src/
├── assets/         # Static assets (images, svgs)
├── components/     # Reusable UI components (Header, Footer, Button, etc.)
├── constants/      # Configuration data and content text
├── pages/          # Full-page views (LandingPage, WhoWeAreDetail, etc.)
├── App.jsx         # Main application router and layout
└── main.jsx        # Entry point
```

## 🛠️ Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Avika125/Nerdx-Digital-Solutions.git
    cd nerdx
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
